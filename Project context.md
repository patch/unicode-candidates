# Project context

This note preserves project decisions and intentions that should remain available across separate chats. It is not a research log, a proposal draft, or a fixed plan for the vault’s structure.

## Current objective

Research and prepare a Unicode proposal for a durian symbol, as predominantly used on signage in Southeast Asian countries. The aim is to establish a strong case for encoding a new character.

## Submission strategy

The project intends to prepare the character and emoji proposals rapidly and in parallel, so that they can refer to each other. The character proposal will be submitted through the standard character-proposal process. The emoji proposal will be submitted once the character proposal has been added to the UTC Document Register and assigned an L2 identifier, allowing that document to be cross-referenced.

## Research status

The project owner has already conducted years of research. That research has not yet been contributed to this project workspace or reviewed here.

## 2026 emoji-submission timing

The current emoji-submission window states: “Currently Accepting Submissions Until 2026-07-31”. The aim is to prepare a proper proposal within that period if possible. If not, the work will proceed at the pace needed for a quality proposal, with the opportunity to publish supporting resources early, engage with the relevant committees, and potentially seek early approval for the following year.

## Research archive and public-facing material

The project will accumulate a larger archive of images than will appear in the formal proposal. Only a select set of the strongest representative images is intended for the proposal. A larger, but still curated, subset may be used for a general-audience project page at `novapatch.ie/en/durian`.

Research from this and other character-proposal projects may become source material for corresponding pages on the project owner’s personal website, whether or not a proposal is approved.

## Collaboration context

Work may take place in separate chats for distinct tasks. When an important project decision, user-provided fact, or durable research finding is not already covered by `AGENTS.md`, add a concise, dated update here or to a more specific note when one exists.

## Status

Organization, data formats, and supporting files will be introduced only when the work creates a real need for them.
